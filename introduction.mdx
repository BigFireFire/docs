Bocha is an AI-powered search and open API platform designed to give developers and businesses a single integration point for intelligent search, flexible payment processing, identity verification, and end-to-end order management. Instead of stitching together multiple third-party services, you get a cohesive set of APIs — all authenticated the same way, all returning consistent response formats — so you can focus on building your product rather than managing infrastructure.

  <Card title="AI Search API" icon="magnifying-glass">

## Who is Bocha for?

Bocha is built for developers and product teams who need to integrate search, payments, or identity verification into their applications without managing multiple vendor relationships.

**Independent developers and startups** can get up and running quickly using the REST API, straightforward authentication, and clear response formats — no lengthy vendor onboarding or complex SDKs required.

**Growing businesses** benefit from Bocha's multi-channel payment support and identity verification, making it easier to serve customers across different payment preferences while meeting regulatory requirements.

**Enterprise teams** can take advantage of sub-account payment flows, redemption code support, and order management to build complex internal workflows, reseller programs, or marketplace platforms on top of a stable API foundation.

## How it works

Getting from sign-up to production integration follows a clear, repeatable path. Here is the typical journey for a new Bocha integration.

<Steps>
  <Step title="Register your account">
    Create a free Bocha account at [app.bocha.ai](https://app.bocha.ai). During registration you'll set up your organization profile, which is used for identity verification and payment reconciliation.
  </Step>
  <Step title="Get your API key">
    Navigate to **Settings → API Keys** in your dashboard and generate a new API key. This key authenticates every request you make to the Bocha API.
  </Step>
  <Step title="Integrate the API">
    Call Bocha's REST endpoints from your application using the Bearer token authentication pattern. Use the [API Reference](/api-reference/introduction) to explore available endpoints and the [Quick Start guide](/quickstart) to make your first request.
  </Step>
  <Step title="Go live">
    Test your integration in a staging environment, verify that your error handling covers authentication and rate-limit responses, then deploy to production. Bocha's consistent response format makes it straightforward to promote from test to live with minimal changes.
  </Step>
</Steps>
