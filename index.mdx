## Get up and running in three steps

New to Bocha? The path from zero to your first successful API response is short. Follow these steps to get started quickly.

<Steps>
  <Step title="Sign up for a Bocha account">
    Visit [app.bocha.ai](https://app.bocha.ai) and create your free account. No credit card is required to get started.
  </Step>
  <Step title="Get your API key">
    Once logged in, navigate to **Settings → API Keys** in your dashboard and generate a new key. Keep it safe — you'll use it to authenticate every request.
  </Step>
  <Step title="Make your first API call">
    Pass your API key in the `Authorization` header as a Bearer token and call any Bocha endpoint. Check out the [Quick Start guide](/quickstart) for a copy-paste example.
  </Step>
</Steps>
