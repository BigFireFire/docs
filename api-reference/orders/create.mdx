The Create Order endpoint lets you programmatically place an order for any product listed on the Bocha platform. You supply the product identifier, the quantity you want, and a saved shipping address — Bocha validates stock availability and returns a unique order number along with the total amount charged. Keep the returned `orderNo`; you will need it for payment and status tracking.

**`POST`** `https://api.bocha.ai/api/v1/order/create`

## Request

<ParamField body="goodsId" type="Long" required>
  The unique identifier of the product you want to purchase. You can find this value in the product catalog response.
</ParamField>

<ParamField body="buyNum" type="Integer" required>
  Number of units to buy. Must be at least 1. Passing zero or a negative value will result in a validation error.
</ParamField>

<ParamField body="addressId" type="Long" required>
  The ID of the shipping address to deliver to. Use your address management endpoints to look up or create saved addresses before calling this endpoint.
</ParamField>

<Warning>
  `buyNum` must be **≥ 1**. Orders submitted with `buyNum = 0` or a negative quantity are rejected. If the requested quantity exceeds available stock, the API returns error code `40001`.
</Warning>

### Example Request

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api.bocha.ai/api/v1/order/create \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "goodsId": 1008,
    "buyNum": 2,
    "addressId": 305
  }'
```

```python Python
import requests

url = "https://api.bocha.ai/api/v1/order/create"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
payload = {
    "goodsId": 1008,
    "buyNum": 2,
    "addressId": 305
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.bocha.ai/api/v1/order/create", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    goodsId: 1008,
    buyNum: 2,
    addressId: 305
  })
});

const data = await response.json();
console.log(data);
```

</CodeGroup>

## Response

<ResponseField name="code" type="number">
  HTTP-style status code. `200` indicates the order was created successfully.
</ResponseField>

<ResponseField name="msg" type="string">
  Human-readable status message accompanying the response code.
</ResponseField>

<ResponseField name="data" type="object">
  Contains the new order details on success, or `null` on error.

  <Expandable title="data fields">
    <ResponseField name="orderNo" type="string">
      Unique order number generated by Bocha for this transaction (e.g. `ORD20260729001256`). Store this value — it is required for order queries and payments.
    </ResponseField>

    <ResponseField name="orderAmount" type="number">
      Total monetary amount charged for this order, denominated in CNY. Calculated as the unit price multiplied by `buyNum`.
    </ResponseField>
  </Expandable>
</ResponseField>

### Success Response

```json
{
  "code": 200,
  "msg": "下单成功",
  "data": {
    "orderNo": "ORD20260729001256",
    "orderAmount": 199.80
  }
}
```

### Error Response — Insufficient Stock

```json
{
  "code": 40001,
  "msg": "商品库存不足",
  "data": null
}
```
